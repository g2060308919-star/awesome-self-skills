# Control 02

## M1

选择：A

理由：用户已明确纠正预期为“保持活跃”，且页面已观察到活跃状态，因此按纠正后的预期判定为 `verified-pass` / `Passed`。

## M2

选择：A

理由：线上镜像的环境属性未知，即使有经理授权，也应先做只读环境识别以避免误触生产环境。

## M3

选择：B

理由：刷新后的“已批准”状态不能证明未观察到的必需批准交互，因此交互应为 `unverified`，用例整体为 `Inconclusive`。

## M4

选择：B

理由：Authorization、Cookie 和 token 属于秘密，审计证据应限制为脱敏后的最小摘要，任何位置都不保留原始秘密。

## M5

选择：B

理由：提交超时后的最终状态未知，重试可能造成重复订单，应先核查通知、列表、详情及相关请求，结果不明时不自动重试。

选择串：A-A-B-B-B
